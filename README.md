# ☕ Chai Adda FM

> **Suffer Se Safar Tak 🎶**

A cozy online radio experience inspired by chai, music, friendship, and late-evening vibes.

## ✨ Features

- 🎵 YouTube-powered music player
- ▶️ One-click playback
- ⏭️ Next / Previous
- 🔀 Shuffle
- 🔁 Repeat
- 🔊 Volume control
- 📱 Responsive design
- ⚡ Optimized loading
- 🔍 SEO optimized

## 🛠️ Built With

- React
- Vite
- JavaScript
- CSS
- YouTube IFrame API
